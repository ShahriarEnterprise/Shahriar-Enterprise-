# Shahriar Enterprise - হোলসেল বিজনেস ম্যানেজমেন্ট সিস্টেম

## 📱 সম্পর্কে
এটি একটি সম্পূর্ণ হোলসেল (পাইকারি) ব্যবসা ব্যবস্থাপনা সিস্টেম যা Hishabee Paikari এর মত বৈশিষ্ট্য প্রদান করে। এই সিস্টেমটি Next.js, TypeScript এবং Supabase দিয়ে তৈরি করা হয়েছে।

## ✨ প্রধান ফিচারসমূহ

### 1. 📊 ড্যাশবোর্ড
- মোট বিক্রয় এবং ক্রয় পরিসংখ্যান
- নেট লাভ/ক্ষতি বিশ্লেষণ
- দেনা-পাওনা সারাংশ
- রিয়েল-টাইম বিশ্লেষণ চার্ট

### 2. 👥 পার্টি ব্যবস্থাপনা (খাতা সিস্টেম)
- গ্রাহক, সরবরাহকারী, বিক্রয় প্রতিনিধি এবং ডিস্ট্রিবিউটর প্রতিনিধি ব্যবস্থাপনা
- ব্যক্তিগত পার্টি খাতা
- ব্যালেন্স ট্র্যাকিং
- স্বয়ংক্রিয় বকেয়া গণনা

### 3. 📦 পণ্য ও স্টক ব্যবস্থাপনা
- আনলিমিটেড পণ্য যোগ করুন
- SKU ভিত্তিক ব্যবস্থাপনা
- রিয়েল-টাইম স্টক আপডেট
- ন্যূনতম স্টক লেভেল সতর্কতা
- ক্রয় এবং বিক্রয় মূল্য পরিচালনা

### 4. 💰 বিক্রয় এবং ক্রয় লেনদেন
- দ্রুত বিক্রয় এন্ট্রি
- ক্রয় অর্ডার ব্যবস্থাপনা
- ক্রেডিট লেনদেন সমর্থন
- ক্ষতিগ্রস্ত পণ্য এবং রিটার্ন ট্র্যাকিং
- স্বয়ংক্রিয় চালান তৈরি

### 5. 📋 খাতা এবং পেমেন্ট
- পার্টি-ওয়াইজ খাতা প্রবিষ্টি
- ডেবিট/ক্রেডিট ট্র্যাকিং
- পেমেন্ট সংগ্রহ রেকর্ড
- বাকি পরিমাণ স্বয়ংক্রিয় গণনা
- একাধিক পেমেন্ট পদ্ধতি সমর্থন

### 6. 💸 খরচ ব্যবস্থাপনা
- বিভাগ-ভিত্তিক খরচ ট্র্যাকিং
- দৈনিক এবং মাসিক খরচ বিশ্লেষণ
- খরচ রিপোর্ট

### 7. 📈 রিপোর্ট এবং বিশ্লেষণ
- দৈনিক বিক্রয় রিপোর্ট
- সময়কাল-ভিত্তিক রিপোর্ট (সাপ্তাহিক, মাসিক, বার্ষিক)
- পার্টি-ওয়াইজ খাতা রিপোর্ট
- লাভ এবং ক্ষতি বিবরণী
- পণ্য-ওয়াইজ বিক্রয় বিশ্লেষণ
- PDF রপ্তানি সুবিধা

## 🛠️ প্রযুক্তিগত স্ট্যাক

- **Frontend**: Next.js 14, React 18, TypeScript
- **UI Components**: Lucide Icons, Recharts
- **Styling**: Tailwind CSS
- **Database**: Supabase (PostgreSQL)
- **Authentication**: Supabase Auth
- **Hosting**: Vercel

## 📦 ইনস্টলেশন

### প্রয়োজনীয়তা
- Node.js 18 বা তার উপরে
- npm বা yarn
- Supabase অ্যাকাউন্ট

### সেটআপ ধাপ

1. রিপোজিটরি ক্লোন করুন:
```bash
git clone https://github.com/ShahriarEnterprise/Shahriar-Enterprise-.git
cd Shahriar-Enterprise-
```

2. নির্ভরতা ইনস্টল করুন:
```bash
npm install
```

3. পরিবেশ ভেরিয়েবল সেটআপ করুন:
```bash
cp .env.example .env.local
```

নিম্নোক্ত তথ্য যোগ করুন:
```
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

4. ডেটাবেস মাইগ্রেশন চালান:
```bash
# Supabase SQL Editor এ supabase/migrations/001_create_business_tables.sql চালান
```

5. ডেভেলপমেন্ট সার্ভার শুরু করুন:
```bash
npm run dev
```

6. ব্রাউজারে খুলুন:
```
http://localhost:3000
```

## 📚 ডাটাবেস স্কিমা

### টেবিল
- **parties**: গ্রাহক, সরবরাহকারী এবং অন্যান্য পার্টি তথ্য
- **products**: পণ্য ক্যাটালগ এবং স্টক
- **transactions**: সমস্ত বিক্রয় এবং ক্রয় লেনদেন
- **ledger_entries**: পার্টি-ভিত্তিক খাতা প্রবিষ্টি
- **payments**: পেমেন্ট রেকর্ড
- **expenses**: ব্যবসায়িক খরচ

## 🔒 নিরাপত্তা

- Row Level Security (RLS) সক্ষম
- প্রতিটি ব্যবহারকারী শুধুমাত্র নিজের ডেটা দেখতে পারে
- সমস্ত API এন্ডপয়েন্ট সুরক্ষিত
- সাধারণ প্রমাণীকরণ সিস্টেম
